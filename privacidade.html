Política de Privacidade — openbot-coletor

Última atualização: 26/11/2026

O que é

O openbot-coletor é uma ferramenta pessoal, usada apenas pelo seu dono, nas contas de e-mail dele. Não é oferecida ao público.

Quais dados acessa

Com a permissão gmail.readonly (somente leitura), a ferramenta lê os e-mails recentes da caixa de entrada e de etiquetas escolhidas pelo dono. Ela não envia, responde, apaga, arquiva nem altera e-mails.

Como usa

Os e-mails são convertidos em texto e guardados num servidor particular do dono, para gerar resumos e organizar documentos (boletos, comprovantes, notas fiscais) só para ele.

Compartilhamento

Os dados não são vendidos, não são usados para publicidade e não são compartilhados com terceiros. Nenhuma pessoa além do dono tem acesso a eles.

Por quanto tempo guarda

As cópias em texto são apagadas automaticamente depois de 30 dias.

Como revogar

O acesso pode ser retirado a qualquer momento em myaccount.google.com/permissions.

Uso limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

English summary: openbot-coletor is a personal tool used only by its owner on the owner's own Gmail accounts, with read-only access. Data is stored on the owner's private server, deleted after 30 days, never sold, never used for advertising and never shared. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions.
